# URL Shortener Service

Build a new URL shortener service: Create a short link for a long URL; Durable storage of links and analytics; Click analytics per link; Horizontal scalability of the redirect path; Versioned REST API with a published contract. Also assumed: 5 capabilities required for production use.

Generated by the agentic SDLC pipeline from the requirement:

> Build a scalable URL shortener service with APIs, persistence, and analytics.

## Quick start

```bash
python -m pytest                                   # unit + integration + contract tests
SHORTENER_API_KEYS=dev-key python -m shortener.main  # serves http://127.0.0.1:8080
curl -s -X POST localhost:8080/api/v1/links -H 'Content-Type: application/json' \
     -H 'X-API-Key: dev-key' -d '{"url": "https://example.com/very/long/path"}'
curl -si localhost:8080/<code>                     # 302 -> target
curl -s localhost:8080/api/v1/links/<code>/stats   # click analytics
```

No third-party runtime dependencies (Python >= 3.10 standard library).

## Endpoints

| Method | Path | Purpose | Auth |
|---|---|---|---|
| `GET` | `/healthz` | Liveness and analytics backlog | public |
| `POST` | `/api/v1/links` | Create a short link | API key |
| `GET` | `/api/v1/links/{code}` | Link metadata | public |
| `DELETE` | `/api/v1/links/{code}` | Disable a link (owner only) | API key |
| `GET` | `/api/v1/links/{code}/stats` | Click analytics for a link | public |
| `GET` | `/{code}` | Redirect to the target URL | public |

Full contract: [`openapi.yaml`](openapi.yaml) - reference: [docs/API.md](docs/API.md).

## Configuration

Defaults were resolved at the requirements gate; override with environment variables.

| Variable | Default | Meaning |
|---|---|---|
| `SHORTENER_CODE_LENGTH` | `7` | Random base62 code length |
| `SHORTENER_CREATE_RATE_PER_MIN` | `60` | Link creations per client per minute |
| `SHORTENER_REQUIRE_API_KEY` | `True` | Require `X-API-Key` on write endpoints |
| `SHORTENER_API_KEYS` | *(empty)* | Comma-separated accepted keys |
| `SHORTENER_ANALYTICS_IP_MODE` | `hash` | `hash` (salted daily hash) or `drop` |
| `SHORTENER_ANALYTICS_RETENTION_DAYS` | `90` | Raw click-event retention |
| `SHORTENER_DEFAULT_TTL_DAYS` | `0` | Default link lifetime (0 = never) |
| `SHORTENER_ALLOW_CUSTOM_ALIAS` | `True` | Allow caller-chosen aliases |
| `SHORTENER_DB_PATH` | `shortener.db` | SQLite file (dev adapter) |
| `SHORTENER_BASE_URL` | `http://localhost:8080` | Prefix for `short_url` |
| `SHORTENER_IP_HASH_SALT` | random per process | Set explicitly for stable unique-visitor counts |
