# ADR-001: Short-code allocation

Status: accepted

## Decision
Random base62 (CSPRNG) + uniqueness constraint + bounded retry

## Alternatives considered
Global counter + base62; hash(url) truncation; pre-allocated key ranges (KGS)

## Rationale and consequences
No coordinator or hot counter, codes are unguessable (no enumeration), collisions are detectable atomically by the store. Cost: one extra write attempt in ~1e-3 cases at 1B links.
